# AMJ Environment — 山野採集統合設計（2026-10-17 作者確定）

**所有・実装正本：** `sucRo-RimWorld/Ancient-Medieval-Japan-Environment`。2026-10-17の作者決定により、別Mod計画 `Ancient-Medieval-Japan-Wild-Food-Foraging` の**全採用済み山野採集仕様をEnvironmentの大型更新へ統合**する。旧リポジトリは設計・監査・診断試験の履歴として残すが、将来の本番ThingDef/食料/Job/画像/発生ルールの独立ownerではない。本書は[Environment総合設計](Design.md)の詳細正本。元となる[12資源の選定根拠](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Wild-Food-Foraging/blob/main/Docs/ResourceAdoption-v1.md)、[採集・植林・前処理](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Wild-Food-Foraging/blob/main/Docs/AcquisitionDesign.md)、[資源別マトリクス](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Wild-Food-Foraging/blob/main/Docs/ResourceAcquisitionMatrix.json) は採択経緯・個別根拠の保存版。旧文書内の「Foragingが所有」「Foragingへ依存」は本書で上書きする。

## 1. 目的・本番範囲

森林・丘陵・山野の植生帯と**その場所で自然に得られる食料**を同一Environment Modで構成し、日本の古代～中世の自然利用を表現する。通常のEnvironment単独利用でも生態・出現・必要な採集動作は成立し、外部Foragingを要求しない。新規PlantDef/菌類Thing、食材Things、画像、Biome自然発生、植林の地域条件、山菜採集・食用適正化の最小動作はEnvironmentが所有する。

- **非対象:** Grainsの穀物生産・製粉・通常料理、Rice Cultivationの水田、Crop Growth Balance、長期乾燥/保存・発酵などの独立加工システム、養殖・栽培菌床、専用狩猟／漁業／海岸採集、薬材加工・治療。毒やアクのある野生素材を**未処理の安全食品として放置しないために必要な最低限の前処理**のみ本機能の成立要件とする。処理Recipe/作業量/栄養値は別途確定する。
- **既存資産保持:** `AMJ_Tree_Shii`と`AMJ_Tree_Beech`のDef/伐採木材/元植林・自然分布を維持。シイの実は木を伐らず採る別動作として同一Mod内に重複PlantDefなしで追加する。旧WFFの抽象XML/テスト用仮Defや仮Steel食材を製品として取り込まない。
- **農業との関係:** 最終的な受入基準は**Environment＋Grains＋Rice Cultivation等のAMJ全部入り世界**。採集と農業の供給バランス・労力・季節・地域差の調整は統合前から必須であり、独立Mod統合によって新規発生したリスクではない。自然食料が穀類栽培を常に不要にする無限供給・均一spawnを避ける。収量や栄養を比率合わせで推定・仮確定しない。単独Environmentにも不自然な食材飽和を起こさない。
- **種リスト:** 他Modに同種があっても、採用済み12資源の可否は変えない。VE/非VE/MO等のソース監査は実装の重複・互換や省コスト技術選択に使い、歴史上の採否と混同しない。

### 山野食料のゲーム上の価値（2026-10-26 方針のみ・実装延期）

山野食料を**畑の完全な代替品にも、序盤だけの無意味な弱い食料にも固定しない**。農地を使わず季節的に得られる森林・山野の食料であり、必要に応じて備蓄・凶作時の補完となる位置づけとする。史実における利用の確度と、ゲーム内での採集・加工負荷・食料価値は別々に根拠付ける。

- 環境側の分布・宿主・季節・自然再採集限界・採集移動／作業、および必要最低限の安全な可食処理で、畑作物・穀物と異なる選択肢を作る。**無限の自動再収穫、どこでも同量発生、自然採集だけで通年の全食料を容易に代替する仕様は避ける。** 一方で農業が整った後も地域・季節に応じて活用できる余地は残す。
- 木の実は採用済みの**スダジイ・クリ・クルミ・カヤ**を対象とし、それぞれの殻・安全処理は必要性が確かめられた範囲だけ実装する。**コナラ／クヌギ等の汎用ドングリ、トチの実は採用済み12資源に含めず保留**。アク抜きと時代・部位の利用根拠なしに「ドングリ」共通の安全な生食品Defを追加しない。
- 個別栄養量・採集数・加工Work・保存日数・再採集期間・生息密度・農業との具体比率は**すべて未決定**。既存採集12種の採否・植林可能範囲・薬用植物保護などの承認は変更しない。比較の前に仮数値を採用したり、この方針だけで新料理や長期保存設備を作ったりしない。
- **作業順序:** 当面はAgriculture側の作物用途・生産・料理・輸入の整理を優先。Environmentの山野採集は後続の森林・野生食料更新で実装し、Agricultureの農産物の実際の価値に照らしてまとめて比較する。既存の環境植生・湿地の公開作業へ山野食料実装を混ぜない。

## 3. 野生出現・植林・採集の拘束仕様

- 自然分布はEnvironment Biome・緯度/気温・標高・湿度・地形・宿主に応じて**生態的に制限**する。湿地・中間温帯林（候補）・暖温帯・冷温帯を全部同じ植物リストで埋めない。既存植生・樹木密度・植林候補・木材供給を破壊しない。モミ・ツガ等の中間温帯森林帯は**別案件の設計候補であり、本統合だけで第5Biomeを実装したとみなさない**。
- 樹木：既存シイのTreeSowing/地域分布は不変。新規クリ・クルミ・カヤはTreeSowing研究後、**その自然分布地域に限り**既存栽培ゾーンから植林可能とする。食材を得たことで伐採木材を失わない。
- フキ・ウドは既存栽培ゾーン植栽を許容する。ワラビ・ゼンマイ・自然薯は第1段階で野生専用、3種類のキノコも自然発生専用で植栽・菌床栽培なし。Fuki/Udoも農業作物を置き換える無制限な栽培物として扱わない。
- 4種類の採集経路は（1）樹木を残す種実採集（2）多年草の若芽・葉柄採集（3）地下部の掘り取り（4）菌類の子実体採集。それぞれRimWorld既存の収穫/Designation/Jobで可能な範囲を使い、既存機構では木材・親株・宿主を保持できない場合のみ必要最小限のC#を追加する。収穫済み状態・Job中断/予約/再採集・保存ロードの整合を確保する。
- 現行の旧Foraging試作は**テスト専用**の抽象PlantBases、合成採集量・鉄製マーカー、Shii採集試作およびテストFixture。過去の原物1.6 Vanilla＋Environment診断PASSは個別の技術的可能性の証拠であり、統合後の正式野生食料・本番Job・旧セーブ・四プロファイルのPASSではない。

## 4. 実施順序・公開と受入境界

1. Environment既定の湿地4種（葦/ヨシ、スゲ、ハンノキ、ミズゴケ）と**次期目標0.2.0**を先に完成。予定バージョンを1.0.0へ書き換えない。今の不完全な湿地版に山野食料を混ぜない。
2. 次の森林植生拡張において、中間温帯林の独立Biome要否・モミ/ツガ/シデ/クリ/ナラ等の代表樹種と出現域を生態資料で具体化。スギ・ススキ等の既存優先度Aの作業を黙って撤回しない。画像は採用の品質ゲートを維持する。
3. 選定済み12資源のThingDef、食材、既存樹木への独立採集、自然発生の種別/立地制限、安全な最小前処理をEnvironmentに移植・実装。旧WFFは本番Modとして起動させない。
4. **AMJ全構成で**山野食料が農業・狩猟・冬季備蓄の役割を侵食しないか、季節食料供給、労働投入、貯蔵/腐敗、植林・木材との競合を調整。同時にEnvironment単独の成立も確保。
5. 本番ソースが揃ってから必要最小の一括実機試験（1.6/1.7対象、Vanilla/MO/CCTO等の互換条件、既存セーブ追加、採集・生育・保存再ロード）を行う。**ゲーム起動や新Workflowを文書整合だけのために行わない**。画像・説明・タグ・バージョン・配布は未承認状態を守る。

旧Foragingから移すのは設計/知見であって、旧リポジトリを依存する・二重配布する・未採用ソースを有効化することではない。旧Foragingリポジトリ/履歴は削除しない。
