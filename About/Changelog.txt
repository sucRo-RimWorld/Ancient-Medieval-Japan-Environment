# Changelog for Ancient & Medieval Japan - Environment
# Current version notes are submitted with an author-approved GitHub Actions Steam update.

0.2.0 - Add four wetland plants to natural Japan-oriented biomes
- Add native reed (Ashi/Yoshi), sedges (Suge) and Japanese alder (Hannoki) to temperate swamps and cool bogs, and sphagnum moss (Mizugoke) to cool bogs.
- Reed and sedges yield base Hay 2 and 1; alder yields base wood 24; sphagnum produces no harvest item.
- Add the accepted wetland-plant artwork for reeds, sedges and alder. Sphagnum temporarily uses the Vanilla moss graphic.
- Continue to recommend a new game for world-generation changes. Adding to existing saves remains unverified; do not remove from saves using added terrain, biomes or plants.

- 葦は干し草2、菅は干し草1、ハンノキは木材24を基本収量とし、水苔は採取物なし。

0.1.1 - Corrected natural biome generation and production loading
- Distinguished warm-temperate and cool-temperate forest world-map textures using existing Vanilla art; biome generation and vegetation are unchanged.
- Fixed new-world surface biome selection so ten excluded Vanilla biome identities, including TropicalRainforest and TropicalSwamp, cannot enter native Worker scoring.
- Retained TemperateSwamp, ColdBog, water and the four AMJ vegetation bands; compatible Medieval Overhaul biome scoring remains available. Both retained wetland types can generate naturally, but each seed need not contain both.
- Removed the developer Quickstarts conditional load path from the production loader. Development tests now load through a separate temporary observer Mod.
- Verified the preceding candidate in Vanilla, Medieval Overhaul, CCTO and MO+CCTO with native map generation and cutting checks, complete logs and zero runtime ERROR.
- Existing saved worlds are not regenerated by this update. Steam upload and downloaded-package verification remain separate from candidate testing.
- Add DDS textures

0.1.0 - Workshop change-note tracking started
- Began the active audit of inherited Vanilla vegetation for ancient-to-medieval Japanese fit.
- Removed Vanilla Poplar from the warm-temperate forest.
- Removed warm-temperate Vanilla Oak and transferred its share to Sudajii so tree density is not reduced.
- Removed generic Pine from the subalpine forest and transferred its share to Shirabiso.
- Removed generic Pine, Birch, Dandelion, and Astragalus from the alpine zone while preserving total vegetation and woody commonality through Haimatsu, grass, and moss.
- Japanized inherited TemperateSwamp and ColdBog vegetation while preserving each biome's total vegetation and woody commonality.
- Documented the existing Japan-oriented wildlife distribution: curated Vanilla animals are used as functional proxies and unsuitable placeholders are excluded.
- Synchronized README, Workshop, 2game, and About wording with the current vegetation-audit status.
